# Prior art for Pandora, 2026-09-22

Desk research (vendor docs, DeepWiki), no trials. Pandora as
compared: a `pnpm` PATH shim and a per-user daemon route claimed argv forms from
agent worktrees to Incus clones of a warm golden on one Linux box; repo-owned
`pandora.toml` and runner scripts; artifacts back before exit; exits 70/75/124/130;
local fallback only before `accepted`; a local lane that replaces Pueue.

## Is transparent PATH interception something serious tools do?

Yes, but almost only for **idempotent, hermetic, short** work. distcc, ccache and
icecc masquerade as `gcc`; corepack, Volta, asdf and mise do it for version
selection. Nx Agents intercept `nx` inside CI, which is interception at the
build-tool level. No agent-era offload tool does it. BuildBuddy, Blacksmith,
Crabbox and OpenClaw's "remote test proof" [29] all use an explicit wrapper and
teach agents with a skill file. Pandora is the outlier here.

The documented downsides, all of which Pandora has already met:

- **PATH order.** ccache: the symlink directory must precede the real compiler [28].
  Pandora hit this with `~/.zshenv` prepending Homebrew.
- **Recursion.** distcc strips its directory from PATH and still reserves exit 111
  for "recursive call to distcc" [27]. Pandora hit this when Pueue re-entered the shim.
- **Stacked wrappers conflict.** ccache warns that masquerading clashes with other
  wrappers; use `prefix_command` [28]. Corepack is the live case for Pandora.
- **Invisibility.** mise: `which` points at the shim, IDEs and non-interactive
  shells need their own setup, and repeated shim calls cost resolution time; it
  recommends activation over shims for interactive use [30].
- **Semantics drift under fallback.** Bazel's own issue calls local fallback
  unsafe because the environments differ [3].

Justification: agents follow `AGENTS.md` imperfectly and forget wrappers; a
shim is the only design that does not need their compliance. The cost: Pandora must be as robust as a compiler wrapper for commands that run
for minutes and boot a Compose stack. The alternative to
weigh is the BuildBuddy and Blacksmith shape: a repo `package.json` script or
`tools/validate.mjs` calling `pandora run --`. Acme PR #1500 already does this
for `pnpm validate`, so Pandora ships both shapes today.

## Verdict per choice

**Mainstream:**

- Repo-owned runners that CI also calls: Bazel test rules, Crabbox jobs,
  Testbox's workflow-derived environment [16].
- Snapshot + rsync per invocation: Crabbox, Testbox, `bb remote`.
- Artifacts back before exit: Bazel top-level downloads, Develocity output
  return, Earthly `AS LOCAL`, Nx/Turbo replay. "Missing is not zero" equals
  Crabbox `--require-artifact`.
- Shard env index/total plus an inventory check: this is Bazel's
  `TEST_SHARD_STATUS_FILE` contract [2].
- Warm per-repo base with CoW clones: Codex's cached container, BuildBuddy's
  recycled workspaces and VM snapshots [4], Testbox's warm microVM.
- Reserved exit codes: distcc reserves 100–127; Pandora's sysexits 70/75 and
  124/130 follow shell convention.

**Unusual, and justified:**

- Fallback only before acceptance. It is stricter than distcc, Bazel and
  Develocity, which fall back mid-flight because their units are hermetic and
  idempotent. A 60 s journey with a Compose stack is neither, so this is correct.
- Memory admission with learned reservations. Others size a VM
  (Testbox, Namespace) or declare requirements (Develocity `memory>=2Gi` [11]).
  Justified on one fixed 4-core box; over-engineering on a fleet.
- A system container that owns a private dockerd. Most platforms use Firecracker.
  Incus is justified by an unmodified Compose stack and fixed ports.
- Re-attach after shim death (`pandora wait`): better than Crabbox `attach`,
  on par with Modal `--detach`.

**Unusual, and weakly justified:**

- The local lane that replaces Pueue. The nearest precedent is Develocity's
  local executors [11]. It widens Pandora from an offloader into the machine's
  only scheduler, and that is scope creep with a real blast radius.
- mtime-keyed `--link-dest` dedup. Testbox pays for `--checksum`, and Bazel is
  content-addressed. Fresh worktrees cost 375 MiB each.

## What others have that Pandora lacks, ranked

1. **`pandora doctor` for the shim.** It checks from inside each agent shell
   that the shim wins on PATH, that recursion guards hold and that corepack
   resolves. ccache and distcc document this failure class, and mise has
   `mise which`/`doctor`. **S.**
2. **A per-call placement override that keeps Pandora in the loop.** Examples
   are `PANDORA_WHERE=local|remote` or `pandora run --local --`, as in Buck2
   `--prefer-local`, Earthly `--sat` and Develocity `remoteExecutionPreferred`.
   Today `PANDORA_OFF=1` is the only lever, and it also bypasses the queue and
   the stats. **S.**
3. **Automatic infra retry after acceptance, remote to remote.** Nx retries on
   a different agent [9], Develocity reschedules a partition when an agent
   drops [11], and distcc backs off a bad host. Exit 70 today makes the agent
   decide. Retry once on `infra_failed` with nothing streamed, else exit 70.
   **S–M.**
4. **Flaky marking.** `same_input_as` already exists. Pandora can flag
   fail-then-pass on equal inputs as Nx does [9], then hint it. **S.**
5. **Phase and queue progress.** Examples are Claude `--cloud`'s setup
   checklist [20], Testbox's `queued→hydrating→ready` and Crabbox
   `--timing-json`. Emit `pandora: queued behind 1 run, ~40 s` from learned
   durations. **S.**
6. **Content-addressed source transfer**, as in Bazel CAS and Testbox
   `--checksum`. It fixes the per-worktree cost. **M.**
7. **A per-run page or URL.** Examples are BuildBuddy invocation links,
   Develocity build scans and Claude session URLs. A daemon-served local HTML
   page with log, phases, artifacts and hint. **M.**
8. **Duration-balanced shards.** Develocity partitions by history, and Nx
   assigns continuously [7][11]. Pandora already records durations. Feed them
   to `plan` as a hint, and keep ownership with the repo. **M.**

Not recommended now: memory-snapshot warm pools (BuildBuddy, e2b pause: **L**),
PR comments (Pandora runs pre-push), predictive test selection (repo's job),
continuous Mutagen sync (it breaks the frozen-snapshot invariant, and Mutagen
Compose is deprecated).

## "The tree you tested is the tree you have"

Google's CitC stores every workspace write as a snapshot that can be named and
sent to review [31]. Bazel and Buck2 key every action by input digest. Crabbox's proof mode binds a bundle digest and verifies the receiver's
filesystem [29]. Pandora's frozen manifest plus `input_id` and exit 75 on
source change is the same invariant in the small, and it is the strongest part
of the design. Claude `--cloud` and Codex cloud sidestep it: the agent and the
tests share one remote tree.
